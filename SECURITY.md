# Security policy

GistDroid stores a GitHub personal access token, so security reports are taken seriously.

## Supported versions

Only the [latest release](https://github.com/iamgiven/GistDroid/releases/latest) receives security fixes.

## Reporting a vulnerability

Please **don't** open a public issue. Report it privately through
[**Report a vulnerability**](https://github.com/iamgiven/GistDroid/security/advisories/new) in this
repository's Security tab, with:

- what the issue is and what an attacker could do with it,
- steps to reproduce, and the app and Android versions you used.

You should get a reply within a week. Once a fix is released, the advisory is published, with credit to you
unless you prefer otherwise.

## Scope

In scope: the app's handling of the token and of gist and snippet data, network traffic, and anything that
exposes data to other apps. Issues in GitHub itself should go to
[GitHub's bug bounty program](https://bounty.github.com/).
